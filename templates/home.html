Bienvenue sur l'API REST StageFaso

Cette API permet de gérer les stages et les comptes utilisateurs. Vous pouvez créer, lire, modifier et supprimer des stages via les endpoints REST sécurisés par JWT.

1. Authentification

Créer un compte : POST /api/accounts/register/

{
    "username": "votre_nom",
    "email": "votre_email",
    "password": "votre_mot_de_passe"
}

Se connecter : POST /api/accounts/login/

{
    "username": "votre_nom",
    "password": "votre_mot_de_passe"
}

Réponse : {"access": "...", "refresh": "..."} (tokens JWT)

2. Endpoints Stages

Liste des stages : GET /api/stages/

Requête sécurisée : ajoutez l’en-tête Authorization: Bearer <token>

Détails d’un stage : GET /api/stages/<id>/

Créer un stage : POST /api/stages/

{
    "title": "Stage Python",
    "description": "Apprentissage Django et API REST",
    "company": "StageFaso",
    "location": "Ouagadougou",
    "contact_email": "contact@stagefaso.bf",
    "skills": "Python, Django",
    "deadline": "2026-05-31",
    "link": "http://stagefaso.bf/stage/1",
    "category": "Informatique"
}

Modifier un stage : PUT/PATCH /api/stages/<id>/

Exemple : même structure JSON que pour la création

Supprimer un stage : DELETE /api/stages/<id>/

3. Pagination & Limite

Les endpoints utilisent une pagination par défaut de 10 stages par page. Exemple :

GET /api/stages/?page=2

Limite d’utilisation : 100 requêtes par jour par utilisateur (rate limit).

4. Conseils d’utilisation

  • Utilisez un token JWT valide pour tous les endpoints protégés.
  • Testez l’API avec Postman ou curl pour une meilleure visualisation.
  • Respectez la structure JSON pour POST/PUT afin d’éviter les erreurs.
